# kuangxh9.github.io

Personal site of Xiaohan Kuang. Plain HTML, CSS and JavaScript: no framework, no build step. GitHub Pages serves the repository as is.

## Pages

| Path | Content |
| --- | --- |
| `index.html` | Home: statement, current focus, facts, and Fig. 1, an affinity landscape searched by annealed Langevin samplers (`assets/js/landscape.js`) |
| `research/` | Five directions (binding and activity, generative design, binding sites, molecular co-folding, agentic workflows), earlier work, publications, talks, software |
| `cv/` | Full CV; prints cleanly |
| `about/` | Path, and 琴棋書畫: a small collection of masterpieces (`assets/js/exhibit.js`, `assets/js/go.js`). The colophon is folded into every page's footer. |
| `404.html` | Not found, as a PDB "missing residues" record |

`index.html` is edited by hand. The other pages are generated: edit `tools/build_pages.py` (and `tools/exhibit_html.py` for the collection), then run

```sh
python -I tools/build_pages.py .
```

## The collection (About page)

| Room | Work | Data | Source and licence |
| --- | --- | --- | --- |
| 琴 鋼琴 | Debussy, *Clair de lune* | `assets/art/clair.json` | Mutopia Project no. 1778, typeset by Keith OHara; public domain |
| 琴 吉他 | Tárrega, *Recuerdos de la Alhambra* | `assets/art/recuerdos.json` | Mutopia Project no. 810, typeset by Stewart Holmes; CC BY-SA 3.0 |
| 棋 | Lee Sedol vs AlphaGo, game 4 (2016) | `assets/art/go-lee-sedol-alphago-4.json` | A. Brouwer go archive (CWI), `AlphaGo/LeeSedol/4.sgf` |
| 棋 | Shusaku vs Gennan, the ear-reddening game (1846) | `assets/art/go-shusaku-gennan-1846.json` | A. Brouwer go archive (CWI), `Shusaku/126.sgf` |
| 書 | Wang Xizhi, 蘭亭集序, the Shenlong copy (Tang tracing, attributed to Feng Chengsu) | `assets/art/lanting.jpg` | Palace Museum, Beijing, via Wikimedia Commons `File:LantingXu.jpg`, PD-Art |
| 畫 | Huang Gongwang, 富春山居圖, the Master Wuyong scroll | `assets/art/fuchun.jpg` | National Palace Museum, Taipei, via Wikimedia Commons, PD-Art |

Instrument sounds are recorded samples from [tonejs-instruments](https://github.com/nbrouwer/tonejs-instruments) (CC BY 3.0) in `assets/audio/piano/` and `assets/audio/guitar/`, pitch-shifted and scheduled with the Web Audio API. Nothing sounds until a visitor presses Play or turns the sound on.

The piano room draws Clair de lune as notes falling onto a keyboard; the guitar room plays Recuerdos on a drawn classical guitar, with fingering computed from the notes (not Tárrega's own). Both read the audio clock, corrected for output latency.

To replace the two scroll images, download the originals from Wikimedia Commons and run

```sh
python -I tools/add_art.py . path/to/LantingXu.jpg "path/to/富春山居圖(無用師卷).jpg"
```

which resizes them, records their size and credits, and rebuilds the page. Either path may be `-` to skip it.

Data converters: `tools/sgf2json.py` (game records), `tools/midi2json.py` (scores). The XK monogram (an X beside a K drawn as a stereocentre: the stem is two in-plane bonds, the arms a solid and a hashed wedge) is generated by `tools/monogram.py`, which writes `assets/img/mark.svg`, `assets/img/favicon.svg`, the bitmap icons, and the inline header version `tools/mark-inline.txt` used by every page. Research schematics are drawn by `tools/schematics.py` from RDKit 2D coordinates stored in `tools/molecules.json`; the co-folding and agent-trace figures are animated by `assets/js/site.js`.

## Visitor counter

A small Cloudflare Worker with a D1 database (`analytics/`) counts page views by day, page and country, without cookies or stored IP addresses, and the home page shows the aggregate as a dot-matrix world (`assets/js/footprint.js`, map data `assets/data/world.json` from `tools/worldmap.py`). It is off until the Worker is deployed and its address is set; see `analytics/README.md`.

## Assets

- `assets/css/site.css`: the design system. Tokens (color, type roles, spacing, motion) are at the top.
- `assets/js/site.js`: theme, load choreography, reveals, nav, the stroke-order writing of the mark on hover, the 404 typewriter, grid overlay (press G).
- `assets/img/`: mark, favicons, portrait crops, `og.png`.
- `assets/file/xiaohan_kuang_cv.pdf`: the downloadable CV.
